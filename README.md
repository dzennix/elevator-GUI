# Elevator GUI

An academic engineering project developed using GNU Octave as part of the Introduction to Engineering course at the International University of Sarajevo.

## About the Project

Elevator GUI is a team-developed project that explores how a smart elevator interface could improve passenger experience, elevator monitoring, energy efficiency, and emergency response.

Inspired by everyday elevator use, the project combines interactive passenger controls with monitoring features, time-based operating modes, and simulated emergency scenarios.

## Key Features

- **Smart Request Queue Management:** Organizes elevator requests.
- **Wait Monitoring:** Provides functionality for monitoring passenger waiting times.
- **Energy-Saving Automation:** Incorporates energy-conscious operating modes.
- **Time-Based Adaptability:** Adjusts simulated elevator timing according to the time of day, with different operating modes for weekdays and weekends.
- **Emergency Priority System:** Supports priority handling for emergency scenarios.
- **Motion-Sensor Door:** Demonstrates motion-sensor-based door functionality.
- **Emergency Scenarios:** Includes simulated responses for fire, flood, and earthquake situations.
- **QR Code Feedback System:** Provides a feedback mechanism for users.
- **Song Request Integration:** Adds an interactive passenger entertainment feature.

## User Interface

The application includes four main interface panels:

1. **Elevator Status Panel** — Displays elevator status information.
2. **Cabin Interface Panel** — Provides passenger controls.
3. **Control and Monitoring Panel** — Supports elevator monitoring and control.
4. **Emergency Control Panel** — Provides access to emergency-related controls.
